# Getting started

Start here if you are new to HPC. Follow these steps in order.

1. [Request an account](./account.md).
2. [Connect using SSH](./connect.md).
3. [Submit your first job](./first-job.md).

:::tip
Use the login node for editing, file management and submitting jobs. Run intensive computation on allocated compute nodes.
:::
