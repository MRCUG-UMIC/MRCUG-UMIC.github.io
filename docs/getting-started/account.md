# Account access

Account eligibility, approval and identity verification are institution-specific.

1. Confirm eligibility and any required training with the HPC team.
2. Request an account through your institution’s approved process.
3. Enable multi-factor authentication if required.
4. Receive your approved username, login hostname and project allocation.

:::warning
Do not publish credentials, tokens, private keys or real user data in documentation or support tickets.
:::
