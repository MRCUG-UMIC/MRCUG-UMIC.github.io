# Data security

This page is **general guidance, not a substitute for institutional policy**.

- Classify datasets before transfer or analysis.
- Confirm consent, ethics, contracts and data-use permissions.
- Use approved storage, encryption and access controls.
- Avoid copying confidential data to personal devices.
- Share only minimum necessary access.
- Follow incident response and retention requirements.

For human genomic data, confirm whether additional controlled-access conditions apply.
