# Data security
- Data is stored on the UMIC under strict controlled-access. Public resources such as human reference genome(s) and metagenomic databases are available to all users. 
- UMIC HPC users are required to de-identify datasets before transfer or analysis, where applicable. 
- For project-specific data (e.g. data from the Uganda Genome Resource), users are advised to conduct all analyses on the HPC. 

For more information, please contact the UMIC HPC System Administrator: beatrice.dhaala@mrcuganda.org
