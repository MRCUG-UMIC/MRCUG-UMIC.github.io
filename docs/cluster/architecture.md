# Cluster architecture

A typical HPC installation has login nodes, compute nodes, shared storage and a job scheduler. Actual hardware varies by institution.

| Component | Purpose |
| --- | --- |
| Login nodes | Secure access, code editing and job submission |
| Compute nodes | CPU-intensive workloads |
| GPU nodes | Accelerated computing, where available |
| Shared storage | Project datasets and outputs |
| Scheduler | Allocates resources and manages queues |

**Administrator checklist:** publish verified CPU/GPU specifications, RAM, partitions, limits, filesystem paths, maintenance windows and network guidance.
